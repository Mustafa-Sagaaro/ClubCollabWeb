# ClubCollab Web

Statische Website von ClubCollab (Microsoft 365 für Vereine).

## Inhalt
- Seiten: `index.html`, `angebot.html`, `ueber-uns.html`, `kontakt.html`, `agb.html`, `datenschutz.html`, `impressum.html`, `404.html`
- Kontaktformular: `kontakt.php` (PHP-Mail, läuft auf Hostinger)
- Assets: `assets/` (CSS, JS, Logos, Icons, Bilder)
- Server/SEO: `.htaccess`, `robots.txt`, `sitemap.xml`

Nicht enthalten: Portal-Demo und Konzepte (eigene Repos bzw. lokal).
